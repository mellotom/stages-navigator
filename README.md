# stages-navigator

travelers guide for building launch sequences: a one-page reference for **mutable instruments stages**, the six-segment modulation builder. the type button, how gates make groups, what one segment becomes, the envelope rules, the extended sequencer, the secret ouroboros oscillator, patches and specs.

sources: the mutable instruments stages manual and secrets page, and the 2020 extended sequencer firmware notes.

not affiliated with mutable instruments.
